# 竞赛论文自审与同题对照

先用原题验收自己的答卷，再看同题作品的思路和结构。2025 年亚太赛公开评阅原则可用于练习中的定性自查。正式赛时核对对应年份与赛项的规则，记录规则版本和需要提交的文件。[2025 参赛规则](https://m.saikr.com/contest/notice_detail/33634) · [亚太赛章程](https://www.apmcm.org/detail/2436)

| 评阅项 | 自查问题 | 典型证据 |
| --- | --- | --- |
| 审题与歧义 | 每问交付物、硬约束、单位和坐标定义是否有出处 | 原题位置和逐问任务表 |
| 假设与依据 | 每项主要假设依据何在，变化后影响哪问 | 来源、参数表与替代情景 |
| 建模思路 | 读者能否从变量、约束和流程追到所求结果 | 总流程图、每问模型与输入输出 |
| 有效求解 | 答案是否满足题设，全程可行性和最优性各验到哪一步 | 求解状态、复跑命令和首个越界 |
| 验证与敏感性 | 能否独立复算重点结果，是否测试了影响结论的扰动 | 手算、反例、留出样本或敏感性表 |
| 局限与结论 | 是否按实际证据报告结果和适用范围 | 场景、限制、失败位置和待验证项 |
| 摘要准确 | 各问有没有答案，数字、单位和限制是否与图表一致 | 摘要到结果表与正文的对照 |

## 比较两份解答前统一口径

1. 写下两篇文章解的是哪一问，使用的原始数据、目标、硬约束、可变参数、单位、时间范围和百分比的分母。核对正文定义、表头和关键数字。
2. 条件能对齐时，从同一份输入复算。程序或数据缺失时，将对照范围限在可查证的内容，并给出需要补齐的文件。对获奖稿也使用同样的核验标准。
3. 记录方法差异造成的结论变化，区分已证实的原因和待测解释。结构上可学习如何呈现流程、求解过程与验证证据。引用作者和公开位置。

宇树案例可先对照动作时长。一套方案固定时间，另一套改变时间倍率时，百分比对应的约束和辅助耗能不同。若要比较实际节能，双方先保持同一任务与时间窗口，再用共同能耗口径，核验全程接触与扭矩。可以先交出各自假设下的估计值和校核状态。[宇树案例复盘](robotics-case.md)

## 把建议变成一次复核

三人分别查原题与主张、运行与数据、论文与版式。每个问题写清证据位置、责任人、改动和复查结果。交付先修会改变答案的项，再修文字和排版。组内试评可以用「通过」「需补证据」「需修正」标记，每项给出处和理由。[空白自审表](../templates/PAPER_REVIEW.md) · [终稿复核](final-delivery.md)
