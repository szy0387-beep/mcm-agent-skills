# 常见题型与建模方法

先问「哪种结果能回答这问」。一题里可能同时有直接计算、预测、优化和仿真。按小问选方法，再用共享的单位、范围和版本把产物接起来。

| 题目要你做什么 | 可手算或复跑的基线 | 什么时候值得升级 | 必须核对的结果 |
| --- | --- | --- | --- |
| 算坐标、时间、面积、速率 | 几何关系、量纲、守恒，选一个特例验算 | 条件随时间变化、要验证规模扩张或姿态连续时，用数值计算与曲线 | 单位、方向、端点、边界与是否有多解 |
| 估计参数、解释关系 | 图示和简单回归，报告残差与样本范围 | 残差结构、非线性或分组差异明显时，试有依据的结构项或分组模型 | 缺失、离群、混杂和区间。相关性是否被误写成因果 |
| 预测未来或分类 | 时间序列用上一期或同季历史，分类用多数类，连续量先试均值或线性模型 | 样本和验证范围足够，复杂模型在共同留出集上有稳定收益时 | 时间顺序、数据泄漏、共同误差指标、泛化范围 |
| 评价、排序或多指标权衡 | 统一方向和尺度后，用有依据的等权或给定权重 | 权重有争议时做情景或敏感性分析。确有多个冲突目标时查看 Pareto 解集 | 指标重复、归一化口径、排名翻转、权重来源 |
| 分配、排班、选址、路径 | 小规模枚举或规则法，写清目标与硬约束 | 规模或约束结构需要时选整数规划、图算法或启发式 | 可行性、目标值复算、求解状态与间隙。有无最优性的证据 |
| 模拟运动、过程或队列 | 先跑单时段、单事件或最短轨迹，做一个解析或手算对照 | 关节、接触、异步事件或随机波动决定结果时，引入相应约束或离散事件仿真 | 初末条件、守恒、换段连续性、步长或种子敏感性、场景边界 |
| 设计方案、比较效益 | 把所有候选放到同一任务、输入、约束和指标下 | 参数不完整或环境变化时，给多场景和结论翻转条件 | 单位、分母、时间范围、未满足约束的候选是否被纳入 |

## 把一行题型变成能跑的方案

1. 写出题面原句和实际交付物。逐项区分题设条件、外部量、队伍假设和求解变量。
2. 用一个小输入写下基准预测或预期结果。若需要调参，先确定独立的验证方案。
3. 候选模型用相同输入和评价口径，比较收益和代价。若基线足以答题，先把它做成可验算的完整结果。
4. 给关键输出做两类检查。一类是按原规则计算的正确性检查，例如供需平衡。另一类是改变边界或参数的稳定性检查，例如调整一个需求量，看结论何时翻转。
5. 论文写出当前证据支持的范围。说明用了哪个模型、在哪些条件下成立、对哪些假设敏感。
