  3. 03

    队友独立复核

    手算一个小例子，检查约束和异常输入，再对照程序结果。

    交付验算记录与修正项
  4. 04

    写稿与提交

    逐问写答案，核对数字、图表和引用，按当届规则检查 PDF 与附件。

    交付论文 PDF 与附件

打开 Codex 开题

  1. 从发布页下载 Source code (zip) 并解压。
  2. 用 Codex 打开包含 AGENTS.md 的文件夹。
  3. 把题面和附件放进 cases/我的题/inputs/，再发送练习指令。
