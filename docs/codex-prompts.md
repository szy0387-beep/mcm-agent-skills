# 给数模队的 Codex 调用指南

先把题面和原始附件放进项目。告诉助手**哪一道题、手头已经有什么、这一轮要交什么**。每个阶段用一条具体指令。数据、模型和正文可以通过 `CASE.md` 交给下一位队员。

## 英文题开局

> 用 `$mcm-skill-router` 带我们做一道往年英文题。题面和附件在 `cases/我的题/inputs/`。先确认赛事、年份、题号和标题。只带我们做第一问，翻译关键约束，列清输入、单位和交付物。等我们自己复述并写一个手算预期，再进入建模。

## 已有成果就从这里继续

| 手里有什么 | 可以这样说 |
| --- | --- |
| 有两种模型想法 | 用 `$mcm-model-training` 对比两种方案的输入与假设。找一个它们会给出不同判断的小例子，等我们先算。 |
| 有模型和代码 | 用 `$mcm-code-training` 核对公式、字段和单位。从原始数据独立复算一个数，指出第一处不一致，留下重跑命令。 |
| 有基准，要测试结论 | 用 `$mcm-simulation-training` 在题设允许的范围内变更一个参数。给我基准、改动和结论改变的条件。 |
| 有结果表，只要论文图 | 用 `$mcm-visualization-training` 从指定结果表重画图 2，核对纵轴单位，给英文图注和绘图命令。 |
| 需要出处或书目 | 用 `$mcm-citation` 核对这句结论用的出处，标出具体章节或指标，再把采用的条目接进书目。 |
| 有图表和已验算结论 | 用 `$mcm-paper-training` 按所附模板写已完成的小问，交付带 `main.tex`、资源和书目的源稿及编译结果。核对摘要和正文的数字。 |

## 正式比赛

> 用 `$mcm-skill-router` 协助本次正式比赛，并用 `$ai-usage-disclosure` 核对使用范围和记录。当届规则与题面在这里，下面是队伍已独立完成的工作和本轮需要的辅助。请注明查到的原始证据、仍待核实的数据或引文，以及本次实际使用情况，交由队员复核。

例如亚太赛的 AI 使用规定要求参赛队独立完成核心模型构建、算法设计与求解、结果分析。用案例模板随手登记版本、用途、关键交互、实际采纳和人工复核，按当届规定整理最终披露材料。[披露与学术诚信指南](ai-usage-disclosure.md) · [首赛手册](team-playbook.md)
