# 数学建模方案对照

先把每个结果写成一行，记录题设任务、输入与版本、可改变的决策、保留的约束、指标及单位、分母、范围和验收状态。即使名称相同，也查公式和表的列。

- **口径相同。** 先独立算绝对差和相对差。零基准时保留绝对差并说明分母问题。检查约束是否通过，再判断比较支持何种主张。
- **口径可对齐。** 固定相同输入、约束、时间或样本范围、计算式与基线，复跑两种方法。一次改变一项假设，记录其作用方向。使用同一数据划分或配对随机种子时说明方法。
- **口径无法对齐。** 并列报告原定义和数值，指出缺哪个输入或约束，给一个能区分解释的复算方案。原题另有硬约束时，应保留超限记录和证据范围。

把数值稳定性、模型假设敏感性和真实可行性分别核查。按题意构造边界情景或只改一项的反例。比较失败时，给出首个失败时刻、记录或对象，列实际值、阈值和结果适用范围。区分模型估计、已验算方案与实际观测。

交付可比较性结论、对照表、证据路径和可执行的下一步。可参考[机器人案例的对照复盘](../../../docs/robotics-case.md)及[终稿复核](../../../docs/final-delivery.md)。
