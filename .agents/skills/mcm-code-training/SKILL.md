---
name: mcm-code-training
description: 在数学建模备赛中自主训练把已明确的模型写成可复跑代码、用样例验错和审查实现。适用于模型到程序的交接阶段。
---

1. 从已确定的模型、输入口径和预期值开始。搜索 `$mcm-fast` 及项目中能直接复用的入口。优先跑通“原始输入到结果表”的短链，区分数据读取、核心计算与输出，保留命令、必要依赖、参数和随机种子。
2. 在改动前写下正常样例、单错反例和新输入的预期。独立计算一个关键量，或在小规模下用枚举、手算、另一种实现作对照。预测检查时间切分与泄漏，优化检查逐项约束、目标重算、求解状态及可行解和最优性证据。
3. 在独立输出目录执行入口，用另一份输入复跑，检查程序确实读取新输入且故障能定位。记录可用的求解器和实际运行路径。需要换后端时，明确比较口径并重验正常结果与边界条件。
4. 交付一条重跑命令、一份机器可读结果、简短验证摘要及仍待验证的部分。后续画图与写作从同一次运行的结果取数。稳定且可复用的命令再考虑接入现有入口。
