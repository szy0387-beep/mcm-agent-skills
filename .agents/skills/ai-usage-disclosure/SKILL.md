# AI 使用披露与学术诚信

1. 正式比赛先核对赛事、年份、赛项和官方规则。把队伍需要独立完成的工作写入 `CASE.md`。亚太赛 2026 英文赛项的具体交稿要求见[披露与学术诚信指南](../../../docs/ai-usage-disclosure.md)。
2. 从队员实际记录整理工具名称、版本或型号、机构、日期、用途、涉及小问和稿件位置、关键提示与回复、采纳和修改情况、人工复核人。翻译、代码补全等辅助使用也按当届规则登记。缺失的信息标「待核实」，让实际使用人补充。禁止编造交互记录、型号或日期。
3. 核对数据、文献和关键数值。数据回查原件和处理记录，文献回查原出处及支持的原句，关键数值回查同版本的结果表、计算或复跑命令。禁止伪造、篡改或隐匿会改变结论的证据。证据不足时保留在待核清单，正式终稿补证、删除对应说法或缩小结论范围。标明仿真、假设和合成样本的性质、用途和来源。
4. 按当届规则准备正文标注、书目条目及[独立披露材料](../../../templates/AI_USAGE_DISCLOSURE.md)。只有全队核对后确认未使用且符合当届定义，才填未使用声明。交付披露草稿、对应位置和待补项，由队员核定后使用。
