# 数学建模论文自审

先读原题与实际提交要求。索要稿件、必要附件、关键结果表和复跑命令中的缺项。能查的检查先做，缺证据处记录待验证。评阅口径按赛事和年份确认。没有公开数字评分办法时，报告证据与修订优先级。

1. 按原题逐问列出交付物、硬约束、稿件位置和原始结果位置。单独检查歧义是否改变了答案。先确认原题、坐标定义与单位。
2. 按审题、假设、建模思路、有效求解、检验、局限与结论、摘要七个方面审读。每一项写明可见证据、状态，以及具体修订和复核方法。使用[评阅与证据指南](../../../docs/paper-review.md)。
3. 从同一次运行追溯摘要、正文、表图。复算一个关键数，检查重要结论是否依赖未经验证的场景、范围、可行性或最优性主张。在比较其他论文的结论前，先用 [mcm-model-comparison](../mcm-model-comparison/SKILL.md) 核查口径。
4. 把评阅反馈交给能改动源头的人。建模手改定义、模型或口径，编程手复跑并重出表图，论文手同步摘要、正文和结论。在发现错误的位置恢复验收。
5. 若用户要终稿审核，按[终稿复核流程](../../../docs/final-delivery.md)从收到的源码包解包重编。交付已核查的证据、待验证的假设、按优先级排序的修改清单。使用[自审表](../../../templates/PAPER_REVIEW.md)。
