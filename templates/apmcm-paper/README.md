# 亚太赛英文论文起稿模板

复制 `main.tex` 到自己的论文目录，按真实题目填写赛事年份、队号、题号和论文标题。可以先在 Overleaf 选择 XeLaTeX 编译，也可用本地 Tectonic。

```sh
tectonic main.tex
```

按题号复制模型段的层级。填入模型依据、求解、结果、验证和局限，替换符号表、示例引用及其他占位。摘要单页，按小问写方法、数值、单位和限制。模板参照 2025 亚太赛公开获奖稿的章节组织与版面层级起草，正式提交用当届规定核对页数、匿名、承诺书、AI 报告和支撑材料。[优秀论文公告](https://m.saikr.com/contest/notice_detail/48433)

交给另一位队员从空目录编译，点目录跳转并核对正文起始页码、附录和 AI 报告。对照原题与结果做一次[论文自审](../../docs/paper-review.md)。
